# 等保测评项目经理技能图谱

## 项目管理基础

### 理论框架
- PMBOK 项目管理知识体系
  - 五大过程组：启动 / 规划 / 执行 / 监控 / 收尾
  - 十大知识领域的等保场景裁剪
- 敏捷思维在测评项目中的应用
  - 多系统并行测评的资源调度
  - 整改跟踪的迭代式管理
- 等保行业特性
  - 强合规驱动：报告结论直接面向公安备案
  - 现场窗口期短：受客户业务限制
  - 多干系人：客户方 / 公安机关 / 云服务商 / 安全厂商

### 行业资质与合规
- 测评机构管理要求
  - 《网络安全等级保护测评机构管理办法》
  - 等级测评机构服务认证
  - 机构年度自查与能力验证
- 人员资格管理
  - 等保测评师（初 / 中 / 高级）持证要求
  - 项目负责人资格与签字权
  - 人员保密承诺与利益冲突回避
- 测评活动的法律边界
  - 授权范围内的测试操作
  - 客户数据的采集 / 使用 / 销毁约定

## 测评项目全生命周期

### 过程依据
- GB/T 28449-2019 测评过程指南
  - 测评准备活动
  - 方案编制活动
  - 现场测评活动
  - 分析与报告编制活动
- 与等保全流程的衔接
  - 上游：定级备案材料核验
  - 下游：整改复测 / 年度测评

### 项目启动阶段
- 商机与合同评审
  - 测评范围与定级情况核验
  - 工期与报价评审（系统数量 / 等级 / 扩展要求）
  - 合同条款：交付物 / 付款节点 / 保密条款 / 双方责任
- 项目立项
  - 任命项目经理与项目组组建
  - 立项书与项目编号管理
- 客户准备清单下发
  - 定级备案证明 / 网络拓扑 / 资产清单
  - 管理制度文件 / 上次测评报告
  - 现场配合人员与测试环境安排

### 项目准备阶段
- 资料收集与初审
  - 核验备案信息与实际系统一致性
  - 识别云计算 / 移动互联 / 物联网 / 工控扩展要求
- 工具与环境准备
  - 漏洞扫描器授权与版本更新
  - 基线核查脚本 / 渗透测试工具清单
  - 笔记本 / 免疫U盘 / 现场记录表单
- 项目计划编制
  - WBS 任务分解
  - 里程碑：方案评审 / 现场测评 / 报告初稿 / 报告交付
  - 资源计划：测评师工时 / 设备 / 差旅

### 方案编制阶段
- 测评方案编制要点
  - 测评对象清单（设备 / 应用 / 人员 / 文档）
  - 测评指标选取（通用 + 扩展 + 行业要求）
  - 测控点抽样方法与覆盖率
  - 工具测试点与风险评估（避免影响生产）
- 方案评审
  - 内部技术评审签字
  - 客户确认测试时间窗口与回避项
- 编制类文档管理
  - 测评方案 / 测评作业指导书
  - 访谈提纲 / 单元测评表 / 现场记录模板

### 现场实施阶段
- 进场管理
  - 首次会议：范围 / 计划 / 配合分工确认
  - 客户陪同与机房出入登记
- 现场质量与进度控制
  - 每日站会与进度日报
  - 证据链完整性检查（截图 / 记录 / 签字）
  - 变更控制：范围变化走补充协议或变更单
- 现场风险控制
  - 扫描 / 渗透操作的授权确认与熔断机制
  - 生产系统只读操作原则
  - 数据导出审批与加密存储
- 离场管理
  - 证据交叉复核，缺项当场确认补测计划
  - 现场记录双方签字确认

### 报告编制阶段
- 报告编制规范
  - 公安部测评报告模板（2025 版）
  - 单元测评结果汇总与判定规则
  - 高风险判例引用（2025 版 81 项）
  - 整体测评与综合结论
- 三级审核制度
  - 编制人自查 → 技术负责人审核 → 授权签字人批准
- 报告交付与后续
  - 报告交付会议与结论解读
  - 客户异议处理流程
  - 整改建议书 / 整改复测约定

### 项目收尾阶段
- 档案归档
  - 项目档案完整性检查表
  - 归档保存期限与借阅权限
- 项目复盘
  - 工时与成本核算 vs 报价
  - 问题清单：进度 / 质量 / 客户满意度
  - 经验教训入库（组织过程资产）
- 客户关系维护
  - 满意度调查
  - 年度测评 / 监督测评续约跟踪

## 进度与资源管理

### 进度管理
- 标准工期参考
  - 二级系统：1-2 周完成
  - 三级系统：现场 3-5 天 + 报告 1-2 周
  - 四级系统：现场 1-2 周 + 报告 2-3 周
  - 批量系统（集团化客户）：分批滚动排期
- 关键路径识别
  - 客户资料准备往往是最长等待项
  - 报告审核签字是内部关键环节
- 延期应对
  - 等待客户因素留痕（邮件 / 签收单）
  - 内部资源冲突时的优先级仲裁

### 成本与资源管理
- 报价结构
  - 按系统等级 / 数量 / 扩展要求组合报价
  - 差旅 / 复测 / 加急费用约定
- 工具资产
  - 扫描器 License 数量与到期管理
  - 测试设备台账与校准
- 人力资源
  - 测评师季度可用工时池
  - 高峰期（年底集中测评）的排班策略

## 质量与风险管理

### 质量管理
- 质量体系
  - 机构质量手册与程序文件
  - 年度内审与管理评审
- 项目级质量控制
  - 方案评审通过率 100%
  - 双人测评与证据互检
  - 报告三级审核
- 常见质量问题
  - 证据截图与结论不对应
  - 抽样覆盖不足
  - 高风险项判定依据引用过时

### 风险管理
- 项目风险清单
  - 客户风险：配合度低 / 范围蔓延 / 拖欠款项
  - 技术风险：复杂架构（多云 / 信创）测评能力不足
  - 合规风险：超范围测试 / 数据泄露
  - 进度风险：备案信息与实际不符需重新定级
- 风险应对策略
  - 风险登记册与定期更新
  - 升级机制：重大问题上报机构管理层
- 应急预案
  - 现场测试导致业务异常的熔断与上报
  - 数据泄露事件的应急处置流程

## 沟通与干系人管理

### 客户方沟通
- 关键角色地图
  - 决策者：分管领导 / CIO
  - 执行者：信息中心 / 安全管理员
  - 配合方：运维厂商 / 开发厂商
- 沟通节奏
  - 启动会 / 每日进度同步 / 离场汇报 / 交付解读
- 冲突处理
  - 结论分歧：以标准和高风险判例为依据
  - 结论诉求与客观事实冲突时的底线管理

### 监管与第三方沟通
- 公安机关
  - 备案审核问题沟通
  - 测评结果报送要求
- 合作方
  - 云服务商责任矩阵确认
  - 密评机构 / 软件测试机构的协作界面

## 多项目与团队管理

### 多项目并行管理
- 项目组合视图
  - 甘特图 / 资源热力图
  - 统一里程碑与周例会机制
- 批量项目标准化
  - 模板化：方案 / 记录表 / 报告初稿
  - 自动化：基线核查脚本 / 数据整理工具

### 团队建设
- 角色分工
  - 项目经理 / 技术负责人 / 测评工程师 / 质量监督员
- 能力培养
  - 新人带教：标准精读 → 陪测 → 主测
  - 政策跟踪：公安部新规 / 新行标的内部分享
- 绩效管理
  - 项目质量指标（报告退回率 / 客户投诉）
  - 工时利用率与项目贡献度

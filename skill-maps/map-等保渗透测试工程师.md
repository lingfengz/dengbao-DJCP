# 等保渗透测试工程师技能图谱

## 法律法规与授权边界

### 红线意识
- 《刑法》相关条款
  - 第285条：非法侵入计算机信息系统罪 / 非法获取计算机信息系统数据罪
  - 第286条：破坏计算机信息系统罪
  - 第287条：利用计算机实施犯罪
- 《网络安全法》
  - 第27条：禁止非法侵入、干扰、破坏
  - 第44条：非法获取、出售个人信息
- 《数据安全法》《个人信息保护法》
  - 测试中接触数据的保密义务
- 未授权测试 = 违法，无论动机

### 授权管理
- 测评 / 测试授权书必备要素
  - 目标范围（IP / 域名 / 系统 / APP 明细）
  - 测试窗口时间与测试方式
  - 禁止操作（不压测 / 不删改数据 / 不影响生产）
  - 双方签字与联系人（含应急联系人）
- 测试过程留痕
  - 操作日志 / 截图 / 流量记录可追溯
  - 发现高危可利用漏洞的即时通报机制

## 渗透测试方法论

### 标准流程
- PTES 渗透测试执行标准（七阶段）
  - 前期交互（授权 / 范围 / 目标）
  - 情报收集
  - 威胁建模
  - 漏洞分析
  - 渗透攻击
  - 后渗透（权限维持 / 内网横向 / 数据证明）
  - 报告输出
- OWASP 测试指南（WSTG）
- ATT&CK 攻击矩阵（路径映射）

### 等保测评中的渗透测试
- 定位：验证安全措施有效性的测评手段
- 依据：GB/T 28448-2019 相关测评方法
- 与常规渗透的差异
  - 目标是验证而非拿权限，点到为止
  - 结论需对应测评指标与高风险判例
  - 需出具可复核的测试证据链
- 与高风险判定指引的联动
  - 弱口令 / 未授权访问 / 严重漏洞 → 高风险判例引用

## 信息收集

### 外部信息收集
- 域名与资产测绘
  - 子域名枚举：OneForAll / subfinder / dnsdumpster
  - 资产测绘平台：FOFA / Hunter / Quake / ZoomEye
  - CDN 判断与真实 IP 定位
- 端口与服务发现
  - Nmap 全端口 / 服务版本 / 脚本扫描
  - Masscan 批量资产存活探测
- 指纹识别
  - Web 中间件：Nginx / Tomcat / WebLogic / WebSphere
  - 框架识别：Wappalyzer / WhatWeb / 潮汐指纹
  - WAF 识别：wafw00f

### 内部信息收集
- 内网存活探测
  - ICMP / ARP / 端口扫描（fscan / Kscan）
- 凭据信息收集
  - 配置文件中的数据库连接串
  - 历史命令 / 计划任务 / 服务账户
- 域环境信息
  - 域控定位 / SPN 枚举 / 域用户列表

## 漏洞发现与利用

### Web 应用漏洞（OWASP Top 10）
- 注入类
  - SQL 注入：sqlmap / 手工注入 / 堆叠注入
  - 命令注入 / SSTI 模板注入 / XXE
- 认证与会话
  - 弱口令爆破（注意锁定策略与频率）
  - 会话固定 / Cookie 属性缺陷
  - 验证码绕过 / 短信轰炸逻辑
- 越权类
  - 水平越权：遍历他人数据 ID
  - 垂直越权：普通用户访问管理功能
- 文件类
  - 文件上传绕过（后缀 / MIME / 解析漏洞）
  - 任意文件读取 / 下载 / 包含（LFI/RFI）
- 组件与反序列化
  - Fastjson / Shiro / Log4j2 / Struts2 历史 RCE
  - 中间件漏洞：WebLogic / JBoss / Tomcat
- 业务逻辑
  - 支付金额篡改 / 重放
  - 短信验证码逻辑 / 优惠券重复使用

### 主机与网络层漏洞
- 操作系统漏洞
  - Windows：MS17-010 / 域内提权 CVE
  - Linux：DirtyCow / DirtyPipe / SUID 提权
- 网络设备
  - 路由 / 交换设备弱口令与历史漏洞
  - 防火墙策略缺陷验证
- 数据库
  - MySQL / Oracle / MSSQL 弱口令与提权
  - Redis 未授权访问 / 写计划任务
  - MongoDB / Elasticsearch 未授权

### 后渗透
- 权限提升
  - Linux：内核漏洞 / sudo 配置 / CRON 劫持
  - Windows：内核漏洞 / 服务路径劫持 / AlwaysInstallElevated
- 内网横向
  - 密码复用 / Pass-the-Hash
  - 内网代理：frp / Neo-reGeorg / Chisel
- 痕迹控制
  - 最小化操作与现场恢复（等保场景不落盘）
  - 测试数据及时清理（授权约定优先）

## 等保场景化测试用例

### 身份鉴别类
- 口令策略验证：复杂度 / 更换周期 / 锁定
- 双因子认证绕过尝试
- 默认口令与历史泄露口令核查

### 访问控制类
- 未授权访问：管理后台 / API 接口
- 越权测试：ID 遍历 / 角色功能矩阵
- 最小权限验证：普通账户可执行的操作边界

### 安全审计类
- 审计日志可否被删除 / 篡改
- 关键操作是否留痕（登录 / 变更 / 删除）

### 数据安全类
- 传输加密验证：HTTP 明文传输 / 弱 TLS
- 存储加密验证：口令明文存储 / 敏感数据脱敏
- 残余信息：测试账号 / 注释中的敏感信息

## 报告编写与整改验证

### 报告结构
- 测试概述（范围 / 方法 / 时间 / 授权依据）
- 风险等级定义（高 / 中 / 低判定标准）
- 漏洞详情
  - 漏洞名称 / 等级 / 影响系统
  - 复现步骤（可复核的请求 / 响应证据）
  - 危害分析
  - 修复建议（具体到配置 / 代码 / 架构）
- 附录：工具清单 / 测试过程记录

### 整改验证
- 修复后复测与回归验证
- 整改闭环确认（复测报告 / 遗留风险说明）

# 密评工程师技能图谱（商用密码应用安全评估）

## 法律法规基础

### 核心法律
- 《中华人民共和国密码法》（2020-01-01 施行）
  - 核心密码 / 普通密码 / 商用密码分类管理
  - 第27条：关基使用商用密码保护并开展评估
- 《商用密码管理条例》（国务院令第760号，2023-07-01 施行）
  - 商用密码检测认证体系
  - 关基运营者每年至少一次密评（第三十八条）
  - 网络安全审查中的密码审查衔接
- 《网络安全法》《数据安全法》
  - 密码保护作为网络安全的基础性措施
- 配套政策
  - 商用密码应用安全性评估管理办法
  - 密评机构与人员管理要求
  - 金融 / 能源 / 交通等行业密评实施细则

### 密评的对象与频次
- 必评对象
  - 关键信息基础设施（每年至少一次）
  - 等保三级以上网络（按国家密码管理部门要求）
  - 政府投资 / 财政支持的重大项目信息系统
- 评估时机
  - 规划阶段：密码应用方案评估
  - 建设完成后：上线前评估
  - 运行阶段：年度评估 / 重大变更后评估

## 密码标准体系

### 核心标准
- GB/T 39786-2021 信息系统密码应用基本要求
  - 技术要求四层面 + 管理要求四层面
  - 一至四级差异化要求
  - 取代 GM/T 0054-2018
- GM/T 0115-2021 信息系统密码应用测评要求
  - 单元测评与量化评估规则
- GM/T 0116-2021 信息系统密码应用测评过程指南
  - 测评流程 / 报告模板 / 证据要求

### 配套标准
- 密码算法类：SM2 / SM3 / SM4 / SM9 / ZUC 系列标准
- 密码产品类：各类密码产品检测规范
- 密码应用类：GM/T 0024 SSL VPN / GM/T 0022 IPSec VPN
- 行业标准：金融 GM/T 0134 等、政务、能源行业密评指引

## 密码应用技术框架

### 四个技术层面（GB/T 39786）
- 物理和环境安全
  - 门禁系统密码应用（IC 卡 / 读卡器合规）
  - 视频监控数据的完整性保护
- 网络和通信安全
  - 通信信道机密性 / 完整性（国密 VPN / TLS）
  - 身份鉴别：证书双向认证
- 设备和计算安全
  - 设备登录身份鉴别（USB-Key / 证书）
  - 系统资源访问控制信息完整性
  - 日志与镜像数据的完整性保护
- 应用和数据安全
  - 应用身份鉴别（数字证书体系）
  - 重要数据传输 / 存储的加密与完整性
  - 抗抵赖：数字签名 / 时间戳

### 四个管理层面
- 管理制度
  - 密码应用方案与管理制度文件
  - 密钥管理规则
- 人员管理
  - 密码应用岗位设置与职责
  - 人员上岗培训与考核
- 建设运行
  - 密码应用方案设计（论证 / 评审）
  - 密码产品采购合规（认证目录内）
  - 运行期密钥管理与应急处置
- 应急处置
  - 密码应用应急预案与演练
  - 密钥丢失 / 泄露的处置流程

## 密码算法与协议

### 国密算法体系
- SM2：椭圆曲线公钥密码（签名 / 密钥交换 / 证书）
- SM3：杂凑算法（完整性 / 口令存储）
- SM4：分组密码（数据加密，128 位分组）
- SM9：标识密码（IBC，无需证书）
- ZUC：祖冲之序列密码（4G/5G 通信）

### 密码协议与应用
- 国密 TLS：GM/T 0024 / RFC 8998（TLS 1.3 国密套件）
- VPN：IPSec VPN（GM/T 0022）/ SSL VPN（GM/T 0024/0025）
- PKI 体系：SM2 证书格式 / 双证书机制 / RA-CA 架构
- 数字信封：SM4 加密数据 + SM2 加密密钥的混合应用

### 算法选用合规
- 禁用：MD5 / SHA1（完整性场景）/ DES / RC4 / RSA-1024 以下
- 过渡关注：RSA 2048（密评中需逐步替换为 SM2 体系）
- 国际算法兼容场景的双证书改造方案

## 密码产品与基础设施

### 常见密码产品
- 服务器密码机（签名验签 / 数据加解密）

- 智能密码钥匙（USB-Key）/ 智能IC卡
- 云密码资源池 / 密码服务平台

### 产品合规要求
- 商用密码产品认证证书（认证目录内选型）
- 产品检测依据与有效期核查
- 密码产品的部署位置与调用关系梳理

### 密码基础设施
- 根 CA / 运营 CA / RA 注册中心
- 密钥全生命周期管理
  - 生成：随机数质量与密码机内生成
  - 分发 / 存储 / 使用 / 更换 / 销毁
- 时间戳服务与抗抵赖基础设施

## 密评实施流程

### 评估准备
- 被测系统调研
  - 网络拓扑与密码应用现状梳理
  - 密码产品清单与证书收集
  - 密码应用方案（规划阶段文档）核查
- 测评方案编制
  - 测评对象与方法确定
  - 单元测评指标映射（四技术 + 四管理层面）
  - 现场测评计划与客户配合清单

### 现场测评
- 文档审查
  - 密码应用方案 / 论证意见
  - 密码产品认证证书
  - 管理制度与运行记录
- 配置核查
  - 密码设备配置策略检查
  - 应用系统密码调用配置
- 工具测试
  - 密评工具箱：算法套件抓包验证
  - 验证实际使用的算法 / 协议 / 密钥长度
  - 随机数质量与密钥存储方式核验

### 分析与报告
- 单元测评结果判定
  - 符合 / 部分符合 / 不符合
- 量化评估
  - 按层面与重要性加权计算得分
  - 高风险项否决规则
- 测评结论
  - 符合 / 基本符合 / 不符合
- 报告编制与提交
  - 报告经密评机构审核签发
  - 报送行业保护工作部门 / 密码管理部门

## 量化评估与风险分析

### 打分机制
- 各层面权重与测评单元得分
- 修正项：不适用的合理剔除论证
- 扣分规则：部分符合项按程度扣分

### 常见扣分项与失分点
- 算法未替换：MD5 / SHA1 / DES 仍在用
- 自实现密码：代码库自行实现加密（未经验证）
- 密钥管理缺陷
  - 密钥硬编码在代码 / 配置文件
  - 密钥明文存储 / 无定期更换
- 传输保护缺失：内网明文传输未加密
- 无密码产品：未部署任何认证密码产品
- 证书问题：SM2 证书过期 / 链不完整

## 与等保的协同

### 双评联动
- 等保定级备案 → 密评对象确定
- 等保测评与密评的现场工作协同排期
- 三级以上系统：等保 + 密评 + 风险评估的年度组合

### 差异对照
- 等保关注全面安全控制，密评聚焦密码合规与有效使用
- 高风险判定：等保高风险判例与密评高风险项双口径
- 报告用途：公安备案 vs 密码管理部门报送

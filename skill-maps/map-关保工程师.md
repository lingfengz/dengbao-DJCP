# 关保工程师技能图谱（关键信息基础设施安全保护）

## 法律法规基础

### 核心法律
- 《中华人民共和国网络安全法》
  - 第31条：关基范围与安全保护办法制定
  - 第37条：CII 运营者数据境内存储与出境评估
  - 第38条：年度检测评估义务
- 《中华人民共和国数据安全法》
  - 重要数据目录与风险管理衔接
- 《中华人民共和国个人信息保护法》
  - CII 场景下的个人信息处理者义务

### 核心法规
- 《关键信息基础设施安全保护条例》（国务院令第745号，2021-09-01 施行）
  - 运营者主体责任与专门安全管理机构
  - 认定规则与报告义务
  - 每年至少一次安全检测和风险评估（第17条）
  - 采购安全审查（网络产品和服务）
- 公网安〔2020〕1960号《贯彻落实网络安全等级保护制度和关键信息基础设施安全保护制度的指导意见》
  - 等保 + 关保双制度框架
  - 三化六防：实战化 / 体系化 / 常态化，动态防御 / 主动防御 / 纵深防御 / 精准防护 / 整体防控 / 联防联控
- 配套政策
  - 《网络安全审查办法》
  - 《数据出境安全评估办法》
  - 行业关基安全保护办法（能源 / 交通 / 金融 / 广电等）

## 标准体系

### 核心标准
- GB/T 39204-2022 关键信息基础设施安全保护要求（2023-05-01 实施）
  - 分析识别 / 安全防护 / 检测评估 / 监测预警 / 主动防御 / 事件处置六大活动
- GB/T 22239-2019 等保基本要求（关基的基线）
  - 关基原则上不低于第三级
- GB/T 20984-2022 信息安全风险评估方法
- GB/T 36627-2018 网络安全事件应急演练指南

### 配套标准与指引
- 关基认定相关行业认定规则
- 国家网络安全事件报告相关规定
- 网络安全审查相关规范（CCRC 认证体系）
- 行业主管部门关基保护实施细则

## 关基认定与责任体系

### 关基认定
- 认定三要素
  - 行业领域重要性（公共通信 / 能源 / 交通 / 水利 / 金融 / 公共服务 / 电子政务 / 国防科技工业等）
  - 遭受破坏后的危害程度（危害国计民生 / 公共利益 / 国家安全）
  - 业务关联度与依赖性
- 认定流程
  - 运营者申报 → 保护工作部门认定 → 报送公安部门备案
  - 动态调整：重大变更时重新认定
- 关基 vs 等保对象
  - 关基从重要网络设施 / 信息系统 / 工控系统中认定
  - 关基整体与其承载的系统分别定级备案

### 责任体系
- 运营者主体责任
  - 主要负责人（第一责任人）对关基安全负总责
  - 设置专门安全管理机构
    - 机构负责人与关键岗位人员背景审查
    - 参与网络安全和信息化决策
- 保护工作部门
  - 行业主管 / 监管部门：认定 / 监测 / 检查
- 公安机关
  - 指导监督 / 安全检查 / 事件调查
- 国家层面支撑
  - 国家网信部门统筹协调
  - 国家级安全保障力量与信息共享机制

## 六大保护活动（GB/T 39204-2022）

### 分析识别
- 业务识别：关键业务链与依赖关系梳理
- 资产识别：关基资产清单与网络拓扑测绘
- 风险识别：威胁 / 脆弱性 / 已有安全措施分析
- 重要数据识别与目录管理
- 定期更新：每年至少一次风险再识别

### 安全防护
- 网络安全防护
  - 安全域划分与纵深防御架构
  - 通信传输保护与边界管控
- 计算环境防护
  - 关键设备 / 主机 / 应用 / 数据的强化防护
  - 供应链软件（含开源组件）安全管理
- 管理防护
  - 制度体系：方针 / 管理制度 / 操作规程 / 记录表单
  - 人员安全：录用审查 / 保密协议 / 离岗管控
  - 教育培训：全员意识 + 关键岗位专项
- 物理与环境防护
  - 机房安防 / 灾备中心 / 异地备份

### 检测评估
- 自评估：运营者每年至少一次（条例第17条）
- 检测评估内容
  - 制度落实情况核查
  - 技术防护有效性检测（渗透 / 漏扫 / 基线）
  - 风险评估与整改闭环
- 第三方协作
  - 委托专业机构开展检测评估
  - 配合保护工作部门与公安机关的检查

### 监测预警
- 监测能力建设
  - 全网流量监测 / 威胁情报接入
  - 态势感知平台与日志集中分析（留存不少于6个月）
- 预警与信息共享
  - 接收保护工作部门预警通报
  - 向保护工作部门报告重大威胁与事件
  - 行业内信息共享机制

### 主动防御
- 攻击面收敛：暴露面梳理 / 互联网资产最小化
- 威胁狩猎与纵深诱捕（蜜罐 / 欺骗防御）
- 实战化攻防演练
  - 参加护网行动与行业演练
  - 自主红蓝对抗与复盘改进
- 自适应防护：基于行为分析的动态处置

### 事件处置
- 应急预案体系
  - 总体预案 + 专项预案 + 岗位手册
  - 与行业 / 国家预案衔接
- 事件报告
  - 重大事件按规定时限向保护工作部门 / 公安机关报告
- 应急响应与恢复
  - 应急队伍与物资储备
  - 备份恢复：重要数据定期备份与恢复验证
  - 业务连续性：关键业务 RTO / RPO 目标
- 复盘改进
  - 事件调查与根因分析
  - 整改措施与责任追究

## 供应链与采购安全

### 网络产品和服务采购
- 安全审查
  - 影响国家安全的采购需申报网络安全审查
- 供应商管理
  - 准入审查：资质 / 安全能力 / 保密协议
  - 合同安全条款：审计权 / 漏洞通报义务
- 软件供应链
  - 开源组件 SBOM 管理
  - 软件出厂 / 入场安全检测

### 数据与出境
- 重要数据出境安全评估申报
- 数据分类分级与境内存储合规

## 与等保 / 密评 / 风险评估的协同

### 关保与等保
- 关基定级原则上不低于三级并完成备案
- 等保测评是关保检测评估的基线工作
- 关保在等保基础上强化：实战化 / 重点保护 / 联防联控

### 关保与密评
- 关基运营者每年至少一次密评（商用密码管理条例）
- 密评对象与关基资产清单对齐

### 关保与风险评估
- 网络数据安全风险评估（2026-08-20 施行办法）衔接
- 年度评估组合：等保测评 + 密评 + 风险评估统筹排期，避免重复进场

## 监督检查与合规运营

### 外部检查应对
- 公安机关现场检查（三级以上每年一次）
  - 检查重点：责任制 / 制度 / 技术 / 应急 / 数据
  - 提示函 / 通告 / 约谈的应对与整改
- 保护工作部门检查与考核

### 年度合规日历
- 等保测评：按备案周期
- 关基检测评估：每年至少一次
- 密评：每年至少一次
- 数据安全风险评估：按办法要求
- 应急演练：定期开展
- 报告报送：重大事件即时 / 年度总结定期

## 能力进阶路线

### 知识进阶
- 攻击者视角：APT 攻击链 / 实战攻防技术
- 架构能力：关基安全体系规划 / 零信任架构
- 数据能力：重要数据识别 / 数据安全治理

### 业务进阶
- 行业深耕：能源 / 交通 / 金融等关基细则
- 国际对标：NIST CSF / NIS2 / IEC 62443 参照
- 新技术场景：工控安全 / 5G 专网 / 云上关基
